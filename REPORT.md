## 2. Відповідь на контрольне запитання

**Запитання:** `Що таке рекурсія?`

**Відповідь:**

Рекурсія — це спосіб розв’язання задачі, коли функція (або процес) викликає саму себе, розбиваючи складну задачу на менші копії тієї самої задачі.

Приклад рекурсії: 
def recursive_best_time(athletes, index=0):
    if index == len(athletes) - 1:
        return athletes[index]["time"]
    next_best = recursive_best_time(athletes, index + 1)
    return min(athletes[index]["time"], next_best)
